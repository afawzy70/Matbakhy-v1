# Infrastructure documentation coverage and drift report

> **Owner role:** Infrastructure and deployment
> **Status:** REFERENCE — a classified inventory of the existing infrastructure documents and a list of differences between those documents, the repository code and the live Contabo host observed on 2026-10-21; no server change was made.
> **Language / اللغة:** English · [العربية](infrastructure-documentation-coverage-ar.md)

This page answers two questions for a new owner or engineer: which existing infrastructure document can be trusted for what, and where the documents disagree with the running Preview. The current host description is in [Contabo server inventory](../08-infrastructure/contabo-server-inventory.md); the pipeline is in [Deployment pipeline](../08-infrastructure/deployment-pipeline.md).

## Evidence legend

| Label | Meaning |
|---|---|
| VERIFIED LIVE | Observed on 2026-10-21 on the Contabo host by the non-privileged user aiagent, read-only. Only facts in the recorded live-facts note qualify. |
| VERIFIED IN CODE | Read in the repository file named in the row. |
| DOCUMENTED ONLY | A document states it; it was not confirmed live or in code. |
| OUTDATED / INCORRECT | Conflicts with newer evidence (typically Hetzner-era text, or "nothing is deployed" text). |
| NOT VERIFIED | No evidence either way. The administrator command that would settle it is in [Admin read-only verification](../08-infrastructure/admin-readonly-verification.md). |

How the accuracy class in part 1 was assigned: a document is classed by its most important claims for handover. Mixed documents are split in the notes column. The class is a reading judgement by the writer of this page, not an independent review.

## Known limitations and documentation gaps

- Link health in part 1 covers file links only. Anchors and external URLs were not checked by the helper used for this page; the DOC-001 checker covers handbook pages.
- Document classes for 04, 05, 07 and mfa-policy are DOCUMENTED ONLY because the code behind them was out of scope for this page; they are not claimed wrong.
- "Last updated" is the date of the last commit that touched the file, which is not proof that the content was reviewed that day.
- Operations documents carry no Arabic mirror, and this handbook does not rewrite them. The historical banners on the Hetzner documents are committed (01ee348); the body text under them was not rewritten, and the deployment README has no banner. Whether to rewrite those bodies is an owner decision; neither `CLAUDE.md` nor DOC-001 sets a directory-based approval rule for them, and DOC-001 requires affected authoritative documentation to be synchronized.
- Items that only an authorized administrator can settle (firewall state, effective sshd value, live .env values, container limits, backup schedule, CD user) are collected in [Admin read-only verification](../08-infrastructure/admin-readonly-verification.md). No agent ran them.
