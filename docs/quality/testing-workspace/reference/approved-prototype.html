ادخل SSH بحساب إداري مصرح له، واقرأ القيمة من ملف الـ Preview الخاص من غير ما تنشرها في أي شات أو GitHub:

cd /srv/matbakhy-staging/deploy/web-preview
# لو ملف .env موجود هنا:
grep '^PREVIEW_USER_PASSWORD=' .env

المسار ده محتاج تحقق على سيرفرك؛ لو الـ .env موجود في مسار تاني، استخدم المسار الموجود في Runbook. ما تصورش الشاشة وهي بتعرض الباسورد.

استخدم نافذتين منفصلتين في المتصفح (Browser Profile أو نافذة خاصة منفصلة) عشان حساب العميل ما يستبدلش جلسة الطباخ.

كلمات السر الحقيقية: حسابات Preview الأساسية (العميل والطباخ) تستخدم قيمة PREVIEW_USER_PASSWORD في إعداد السيرفر الخاص. لا توجد قيمة ثابتة منشورة أقدر أؤكدها. مش هكتب باسورد مختلق. حساب owner-e2e-ops مش ضمن الـ seed الأساسي؛ يلزم تجهيزه أولًا، وباسورده يُحفظ في ملف private credentials الخاص بالتجهيز.

⚙️ تفاصيل للمطور — افتحها لما تحتاجها

السيناريو الكامل E2E-ORDER-101 كمان فيه خطوة مراجعة إضافية بواسطة owner-e2e-ops بصلاحية order.ops، والحساب ده لازم يتجهز قبل الاختبار الكامل. النسخة الحالية تشمل Keycloak ومراجعة الموظف؛ لا يتم اعتبار الاختبار PASS حتى تنفذ الخطوات الحقيقية وتوثق الأدلة.

Keycloak Realm: matbakhy · Web client: matbakhy-web · API: Public configuration ↗

Seed: كشري تجريبي بسعر مرجعي 75 جنيه للحصة، فالطلب ٢ = 150 جنيه إذا السعر لم يتغيّر. السعر النهائي من الـ API. المواعيد المزروعة ممكن تكون انتهت.
