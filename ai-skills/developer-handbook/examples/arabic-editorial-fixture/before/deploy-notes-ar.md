# ملاحظات النشر

> **Language / اللغة:** [English](deploy-notes.md) · العربية

المستند ده مخرَج حيّ. بيتم تحديثه كلما المشروع يتطور.

الإعدادات موجودة في ملفات مقروء بالآلة تحت `config/`.

قبل ما تنشر، اتأكد إن الـ CI أخضر وإن الـ Schema ماتحركتش.

الفلوس الحقيقية متقفّلة لسه، وكل البيانات هنا صناعية.

لو الـ Deployment فشل، استخدم الـ Rollback للصور بس: ارجع لصور Docker السابقة من غير ما تسترجع قاعدة البيانات.

```bash
./deploy.sh up --release 2.4.1
```

- راجع `config/app.yaml`.
- شغّل `./deploy.sh smoke`.
