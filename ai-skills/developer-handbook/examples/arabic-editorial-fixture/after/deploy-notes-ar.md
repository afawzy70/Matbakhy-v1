# ملاحظات النشر

> **Language / اللغة:** [English](deploy-notes.md) · العربية

الدليل ده بيتحدّث باستمرار مع تطور المشروع.

الإعدادات موجودة في ملفات قابلة للقراءة آليًا تحت `config/`.

قبل ما تنشر، اتأكد إن كل فحوصات الـ CI نجحت وإن مفيش تغيير في بنية أو إصدار الـ Database Schema.

التعاملات المالية الحقيقية مش مفعّلة حاليًا، وكل البيانات هنا بيانات تجريبية غير حقيقية (Synthetic Data).

لو الـ Deployment فشل، ارجع لإصدار Docker Images سابق من غير استرجاع قاعدة البيانات.

```bash
./deploy.sh up --release 2.4.1
```

- راجع `config/app.yaml`.
- شغّل `./deploy.sh smoke`.
